# Ingeniería 2026

Este repositorio reúne las tareas de programación y los archivos necesarios para desarrollar cada actividad.

## Organización

Las tareas se ordenarán por semana dentro de la carpeta `progra`:

```text
progra/
├── semana_1/
├── semana_2/
├── semana_3/
└── semana_x/
```

La `x` corresponde al número de la semana. Por ejemplo, el trabajo de la semana 4 se guardará en `progra/semana_4/`.

Dentro de cada semana podrán incluirse:

- Código fuente y ejercicios.
- Pseudocódigo.
- Pruebas y datos de ejemplo.
- Archivos de configuración o control.
- Cualquier otro archivo necesario para ejecutar, revisar o respaldar la actividad.

## Convenciones simples

- Usar nombres de archivos en minúsculas y con guion bajo: `nombre_archivo.py`.
- Evitar espacios, tildes y caracteres especiales en los nombres.
- Mantener juntos el código y sus archivos de apoyo.
- Guardar en cada semana solamente los archivos relacionados con esa actividad.

Esta estructura podrá ampliarse si más adelante se agregan otras asignaturas o tipos de trabajo.
